# Git Discipline Demo Architecture

A compact handoff for demo repository setup.

## Goal

Show a practical Git discipline model that is enforced by both local hooks and GitHub Actions.

## Included in this demo repo

- Workflow guide: `CONTRIBUTING.md`
- Local commit enforcement: Husky + commitlint + lint-staged
- Local branch enforcement: Husky pre-push branch-name validator
- CI checks: lint, test, typecheck, build
- Server-side policy checks: commitlint workflow + branch-name workflow
- Demo CD: deploy simulation on `main`

## Commands to run after creating the repository

```bash
npm install
npm run prepare
npm run lint
npm run test
npm run typecheck
npm run build
```

## Branch naming rules enforced

- `feature/auth-navigation`
- `fix/crash-on-start`
- `hotfix/crash-on-launch`
- `chore/update-deps`

`main` and `develop` direct pushes are blocked by local pre-push and should also be blocked via branch protection.

## GitHub settings to configure manually

1. Protect `main` and `develop`
2. Require pull requests for merging
3. Require status checks: `ci`, `commitlint`, `branch-name`
4. Require at least one review approval
5. Restrict direct pushes
